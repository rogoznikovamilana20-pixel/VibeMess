## 8. УНИКАЛЬНЫЕ ПАТТЕРНЫ VIBE

### 1. Energy Pulse
Анимация пульсации для активных элементов (AI-индикатор, запись голоса).

### 2. Gradient Border
Градиентная граница вместо сплошной для премиальных карточек.

### 3. Glow Effect
Мягкое фиолетовое свечение вокруг ключевых элементов.

### 4. Glass Morphism
Стеклянный эффект для всплывающих окон и меню.

### 5. Contextual Color
Цвет элементов зависит от контекста (личное = фиолетовый, работа = синий).

## 10. ДОСТУПНОСТЬ (A11Y)

### Контраст

- Текст на фоне: минимум 4.5:1
- Крупный текст: минимум 3:1
- Интерактивные элементы: минимум 3:1

### Touch Targets

- Минимум 48x48dp для интерактивных элементов
- Отступ между элементами: минимум 8dp

### Screen Readers

- Все элементы имеют `contentDescription`
- Группы логически связаны
- Порядок навигации логичен

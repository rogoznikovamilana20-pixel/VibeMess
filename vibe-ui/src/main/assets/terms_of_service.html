Пользовательское соглашение

Версия от 1 августа 2026 г.

1. Общие положения

Настоящее Пользовательское соглашение (далее — «Соглашение») является юридически обязывающим договором между пользователем (далее — «Пользователь») и разработчиком приложения Vibe (далее — «Разработчик»).

Используя приложение Vibe (далее — «Приложение»), Пользователь подтверждает, что ознакомлен с условиями данного Соглашения и принимает их полностью.

Если Пользователь не согласен с условиями Соглашения, он обязан прекратить использование Приложения.

2. Описание сервиса

Vibe — это мессенджер с функциями:

  • Обмен сообщениями (текст, медиафайлы)
  • Голосовые и видеозвонки через WebRTC
  • Создание каналов, групп и ботов
  • AI-ассистент Aurion
  • Marketplace (внутренняя marketplace-площадка)
  • Сквозное шифрование (E2EE)
  • Меш-сеть для общения без интернета

3. Регистрация и аккаунт

Для использования Приложения требуется регистрация посредством адреса электронной почты. Пользователь несёт ответственность за сохранность учётных данных своего аккаунта.

Один пользователь может иметь только один аккаунт. Мультиаккаунтинг запрещён.

4. Конфиденциальность и данные

Приложение收集ает минимальный объём персональных данных:

  • Имя пользователя (отображаемое имя)
  • Адрес электронной почты (для авторизации)
  • Статус онлайн/оффлайн

Номера телефонов не собираются и не хранятся.

Сообщения хранятся на сервере в зашифрованном виде. При включённом E2EE расшифровка сообщений возможна только на устройствах участников чата.

Политика конфиденциальности доступна в разделе «О приложении».

5. Поведение пользователя

Пользователю запрещается:

  • Использовать Приложение для рассылки спама
  • Распространять незаконный контент
  • Совершать мошеннические действия
  • Нарушать права других пользователей
  • Пытаться получить несанкционированный доступ к системе
  • Создавать фейковые аккаунты для обмана других пользователей
  • Использовать ботов для автоматической рассылки без разрешения

За нарушение правил Разработчик оставляет за собой право заблокировать аккаунт без предварительного уведомления.

Все права на Приложение, его дизайн, логотип, код и функциональность принадлежат Разработчику. Пользователю предоставляется неисключительная лицензия на использование Приложения в личных целях.

7. Внутренняя валюта «Искры»

Приложение использует внутреннюю валюту «Искры» ( Sparks ) для покупок на Marketplace и подписки Vibe+. Искры не являются реальной валютой и не подлежат возврату за исключением случаев, предусмотренных законом.

Приложение предоставляется «как есть». Разработчик не гарантирует бесперебойную работу сервиса и не несёт ответственности за:

  • Потерю данных по вине пользователя
  • Временные сбои в работе сервиса
  • Действия третьих лиц
  • Косвенные убытки

9. Изменение соглашения

Разработчик оставляет за собой право изменять условия данного Соглашения. Пользователи уведомляются об изменениях через интерфейс Приложения. Продолжение использования Приложения после внесения изменений означает согласие с новыми условиями.
